# mirecorder

轻量的 macOS 屏幕录制和快速剪辑工具。使用 SwiftUI、ScreenCaptureKit 和 AVFoundation，不需要第三方依赖。

## 功能

- **录制**：选择整块显示器或某个运行中的应用，输出 H.264 MP4。应用模式只采集指定应用的画面和系统音频，麦克风仍可单独选择。
- **音频**：麦克风和系统音频各有实时电平及独立增益，成片混成一条 48 kHz 立体声 AAC 音轨。
- **时间剪辑**：用波形查看录音，拖动 IN / OUT 或输入精确时间。音频分析会标出持续活动的候选区间，便于跳过长时间待机；候选不等同于语音识别结果。
- **画面裁剪**：可以放大预览、定位到需要的帧并拖框，支持移动自由裁剪框和使用比例预设。只剪时间不重编码；裁剪画面需要重编码。

## 本地构建

需要 macOS 15 或更新版本，以及带 macOS 15 SDK 的 Xcode 或 Command Line Tools。

```sh
bash build.sh
open build/mirecorder.app
```

首次录制时，请在 macOS「系统设置 → 隐私与安全性」中允许屏幕和系统音频录制、麦克风访问。默认采用本地 ad hoc 签名，重新构建后 macOS 可能要求再次授权。已有可用签名身份时，可以这样构建：

```sh
CODESIGN_IDENTITY='你的代码签名身份' bash build.sh
```

## 工作流程

1. 在「録画」页选择整屏或应用、麦克风和系统音频，开始录制。应用录制前先打开目标应用的窗口。
2. 停止后自动进入「編集」页；也可以点击「動画を開く…」或按 `⌘O` 打开已有视频。
3. 在波形上确认起止候选，拖动 IN / OUT 微调。点击波形或输入 `3:21` 等时间只会改变预览位置；在预览上拖框可以设置画面选区。
4. 导出为旁边的新 MP4，不覆盖原始录像。新录制文件默认保存在 `~/Movies/mirecorder/`。

录制、分析和剪辑都在本机完成。仓库不包含录制内容、构建产物或授权配置。
